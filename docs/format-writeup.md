# Format des writeups

Chaque page suit le déroulement de la résolution, avec les éléments nécessaires pour vérifier le résultat.

1. **Énoncé et consignes.** Texte original lorsqu'il a été conservé, format de réponse, fichiers remis. Un résumé est explicitement identifié quand le texte original manque.
2. **Artefacts.** Liens vers les entrées, scripts, résultats et images présents dans le dépôt ou dans le paquet d'artefacts.
3. **Analyse.** Pour chaque étape : commande lancée depuis la racine du dépôt, sortie correspondante et ce qu'elle permet de conclure.
4. **Résultat.** Flag obtenu, réponse ou étape atteinte. Pour les dossiers incomplets : résultat intermédiaire concret et point de blocage.

Les blocs de sortie proviennent soit d'un journal conservé, soit d'une nouvelle vérification locale explicitement indiquée. Une commande proposée sans avoir été rejouée est identifiée comme telle. Un calcul long déjà terminé est documenté à partir de ses checkpoints plutôt que relancé intégralement.

Les scripts ajoutés servent à l'analyse locale des fichiers du CTF. Les étapes de soumission au serveur ne sont pas nécessaires pour reproduire les résultats.
